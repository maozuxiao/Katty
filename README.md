# 欢迎来到Katty的资料库

个人博客与文档岛屿，通过 GitHub Contents API 自动列出 `docs/` 下的文档。

## 本地预览

GitHub API 需要 HTTP 环境，直接双击打开 `index.html` 会读取失败：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```
