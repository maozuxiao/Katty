🎯 今日进步清单

不为赶进度，只为今天比上次多感受到一点 ｜ 游完回来告诉我真实感受

8/25 周二 晚 · 腿基础
今天只盯一件事：让腿「吃住水」——翻脚 + 蹬夹方向

① 翻脚做不做得出

做：收腿到末段，主动把脚踝往外翻、脚尖外勾，脚掌像「蛙掌」扣住身后的水。
算进步：你能刻意做出翻脚，且能描述「脚掌是朝后下方的」，而不是脚尖朝下蹬空。
游完告诉我：翻脚是「自然就有」还是「要想一下才做得出」？

② 蹬腿有没有推进感

做：扶板蹬腿 25m，闭眼感受——每次蹬夹，身体是不是被「推」出去一截。
算进步：不靠手划，光腿能把你往前送；哪怕一次只送半米也是进步。
游完告诉我：推进感强 / 弱 / 几乎没有？两条腿哪条更走水？

③ 滑行能不能拉出来

做：蹬完立刻并腿伸直，数「1–2」再划下一次。
算进步：滑行段身体是平的、不沉，且比刚下水时滑得远一点。
游完告诉我：蹬完能滑几秒？滑的时候沉不沉？

④ 累对地方没

做：留意疲劳位置。
算进步：累在小腿后侧 / 脚踝外侧（翻脚发力处），而不是大腿乱抡的累——说明动作对了。
游完告诉我：今天腿累在哪儿？

⑤ 垂直蹬腿浮不浮得住

做：浅水垂直，只蹬腿、手轻拨，看能不能靠腿浮住不沉。
算进步：20 秒内腿成为主要支撑，不靠手忙划。
游完告诉我：垂直蹬腿能不能浮住？
🔑 对比锚点（今天实打实进步的证据）：
下水前先「不翻脚、随便蹬」25m，记住多远、多费劲（这是基准）。练完再用翻脚蹬 25m——同样发力，游后更远 / 更省力 = 今天確实进步了。

游完回来，就告诉我这 5 件事：

  1. 翻脚自然还是有意识才做得出？
  2. 推进感强 / 弱 / 几乎没有？哪条腿更走水？
  3. 蹬完能滑几秒？滑时沉不沉？
  4. 腿累在小腿/脚踝，还是大腿？
  5. 垂直蹬腿能不能浮住？

我拿这 5 条定周四（8/27）的「今日进步清单」：翻脚还卡就继续死磕翻脚；推进感有了就加「蹬夹速度 / 窄收腿」。
