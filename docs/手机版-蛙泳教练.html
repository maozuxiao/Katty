回来告诉我：垂直蹬腿能不能浮住？

📚 技术小抄（点开看）

收翻蹬夹 是什么（4 步）
收脚跟向臀部收，膝间距不超过肩宽（窄收）
翻脚踝外翻、脚尖外勾，脚掌像蛙掌扣住身后水
蹬脚掌对水向后下方蹬出（不是向外踢）
夹快速并拢双腿，蹬完伸直滑行 1–2 秒
不走水 → 翻脚 + 蹬夹方向

翻脚：收腿末脚尖外勾、脚掌对准后方水面——这是走水关键。错：脚尖朝下/朝内，蹬空。

窄收腿：膝不超肩宽。错：膝盖分太开，蹬不到水。

蹬夹：脚掌对水向后下方蹬出，再夹拢并腿。错：只向外踢不夹，无推进。

滑行：蹬完并腿伸直滑 1–2 秒。错：连着划，最费力。

低头蹬腿连贯（换完气不沉）

问题：抬头换气时屁股下掉，换气后停顿再蹬，已下沉。

纠正：换气（头抬）→ 头一入水立刻蹬腿，两件事是一拍、不能断。

节奏：划手抬头吸 → 低头（同时启动蹬腿）→ 蹬夹 → 滑行

口诀：「换完气，头一低，腿就蹬」

垂直蹬腿 怎么练

在哪：浅水区，水深到胸口/肩膀，能站住。

做：脚蹬离池底、身体立直，只做蛙泳腿（收翻蹬夹）把自己撑在水里；手贴两侧或轻轻画小圈保持平衡，别用来往上扒。

为啥有用：腿一停就站回池底，零风险；不用往前游、不用换气、不用管手臂，只抠腿吃水。

算练成：连蹬 20 秒人浮住甚至微离底，两次蹬腿之间不往下沉（蹬完夹拢锁住了）。
