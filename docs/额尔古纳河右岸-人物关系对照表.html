《额尔古纳河右岸》人物关系对照表

作者：迟子建 ｜ 茅盾文学奖作品
说明：本表按思维导图大纲模式组织，直接用 # / ## / ### / #### 层级与缩进列表，可导入 XMind、幕布、Markmap、Obsidian 等工具。
文中"我"为叙述者，全书未给出其姓名（"我不想留下名字了"）。

一、叙事坐标

1.1 叙述者

  • 我：鄂温克女人，九十岁，"我们这个民族最后一个酋长的女人"
    • 出生在冬天，出生当日父亲林克猎到黑熊、取出上好熊胆
    • 幼时被父亲唤作"小乌娜吉"（姐姐列娜为"大乌娜吉"，弟弟鲁尼为"乌特"）
    • 在岩石上画画（伊马其河畔 / 温都翁河岩画）
    • 下山表决时把桦树皮投进火塘（唯一反对者）
    • 结局：与孙子安草儿留守山林，嘱其把自己葬在树上、风中

1.2 叙事结构（一日四时）

  • 清晨：我的出生、父辈的爱情与死亡
  • 正午：日军侵扰、萨满更替、我的两次婚姻
  • 黄昏：定居、文革、山林开发、亲人接连离世
  • 半个月亮：下山与留守的最后抉择

1.3 核心冲突

  • 山林文明 ↔ 现代定居（布苏 / 激流乡）
  • 萨满的"救一人、失一人"宿命
  • 驯鹿、火种、额尔古纳河：民族记忆的三重象征

二、血缘谱系（七大支系）

2.1 林克 × 达玛拉（我的本家）

  • 林克（父亲，阿玛）
    • 氏族最好的猎手，爱枪"仅次于爱达玛拉"
    • 与兄尼都萨满比箭射"猴头蘑"，赢了达玛拉
    • 死于雷电：去阿巴河换驯鹿归途，经密松林时被雷击（同时击断两棵大树），风葬
  • 达玛拉（母亲，额尼）
    • 全乌力楞最能干的女人，爱穿灰裙、爱跳"斡日切"舞
    • 头绾发髻，插月白色鹿骨簪子
    • 死：林克死后疯癫，在鲁尼与妮浩的婚礼篝火旁穿羽毛裙子跳舞至黎明，仰面倒地而亡
  • 子女
    • 长女（无名）：出生两天因风寒夭折，装白布口袋扔向阳山坡
    • 次女 列娜：骑驯鹿时睡着滑落，在睡梦中被冻死
    • 三女 我（叙述者）
    • 四女（无名）：出生不到一天夭折
    • 子 鲁尼（见 2.5）
  • 尼都萨满（伯父，额格都阿玛）
    • 林克的哥哥、乌力楞族长，孤身一人
    • 深爱达玛拉，为氏族规矩所禁（兄死弟可娶嫂，弟死兄不可娶弟媳）
    • 用两年收集的山鸡羽毛为达玛拉缝制羽毛裙
    • 死：为吉田治愈腿伤、战马代死之后，一路丢弃鼓槌、神鼓、神衣、神裙，倒地而亡
  • 依芙琳（姑姑，林克的姐妹）→ 见 2.4
  • 那吉勒耶业（外祖父）：送女儿达玛拉"一团火"，即我终生守护的火种
  • 祖父（无名）：令二子比箭定亲；死于尼都萨满继任萨满时另一氏族萨满跳神之时
  • 猎犬伊兰：伊兰＝"光线"；林克死后独归报信，达玛拉求情免于殉葬

2.2 伊万 × 娜杰什卡（跨国之家）

  • 伊万（伯祖父额格都亚耶之子，与林克同辈）
    • 个矮脸黑，额头一颗红豆似的红痣（易招熊，两次从熊掌下逃生）
    • 手能攥碎鹅卵石、折断松木；氏族铁匠
    • 用皮张从俄国安达手中换回娜杰什卡，握扁铁酒壶吓退安达
    • 娜杰什卡走后拒不再娶："我的生命中只有一个女人"
    • 越狱 → 抗联向导 → 解放军 → 转业满归；死：1968 年因"苏修特务"嫌疑被造反派抓捕，怒咬断两根手指，救回后吐血两天而亡；土葬、头朝额尔古纳河、坟前立十字架
  • 娜杰什卡（俄国人）
    • 被继母卖给安达去做妓女，途中遭安达奸污
    • 既信玛鲁神又拜圣母，胸前划十字（依芙琳最瞧不起她）
    • 由达玛拉教会熟皮子、晒肉干等女活
    • 结局：日本人来那年带吉兰特、娜拉逃回额尔古纳河左岸，下落不明
  • 子女
    • 吉兰特（子，蓝眼睛）：喜做女人活计，文弱
    • 娜拉（女）：最会染布（都柿染蓝、红豆染水红、百合染粉）；留给我一块粉布做嫁衣滚边
  • 额格都亚耶（伊万之父）：因伊万娶娜杰什卡、蓝眼睛的吉兰特出世而吐血三天气死

2.3 老达西—哈谢 × 玛利亚—达西 × 杰芙琳娜

  • 老达西（哈谢之父）
    • 为救驯鹿仔赤手打死母狼，被小狼咬断一条腿
    • 畏光畏雪、不剃发不剃须，日夜盼"奥木列"（孙子）
    • 把哈谢捉来的山鹰训练成猎鹰，也唤作奥木列
    • 死：带猎鹰出营与狼搏斗，狼死，他与鹰重伤后被狼群吃掉；与鹰同葬
  • 哈谢（老达西之子）
    • 捕鱼能手（凿冰眼、持鱼叉）；在斯特若衣查节与玛利亚订婚
    • 曾被召去东大营受训
    • 死：七十岁踩到"黏蘑"滑倒骨折，拒送卫生院，"我要把骨头扔在山里"，三日而亡
  • 玛利亚（哈谢之妻）
    • 长期不孕，见血即哭（锯鹿茸时必哭）；吃罗林斯基的药无效
    • 老达西死后突然"重病"实为怀孕，生下男孩取名达西
    • 逼达西为金得守孝三年才许娶杰芙琳娜；长期虐待杰芙琳娜致其流产
    • 死：1959 年初冬病故，临死拉着杰芙琳娜的手，睁着眼睛走的
  • 小达西（哈谢之子，随祖父之名）
    • 十四岁入东大营受训，偷渡左岸侦察苏联铁路七天，获土黄色棉大衣
    • 在金得火葬现场向刚守寡的杰芙琳娜跪地求婚，守孝三年后成婚
    • 死：1968 年被造反派打断一条腿；1972 年秋剥野鹿皮后用猎枪自杀
  • 杰芙琳娜（先嫁金得，后嫁达西）
    • 能干温和、嘴角微歪；金得婚礼当日即守寡
    • 受玛利亚罚跪毒打、被迫滚坡流产后再不孕
    • 死：达西自杀后，抱其头颅舔净血迹，采毒蘑吃下殉情，与达西合葬

2.4 坤得 × 依芙琳 → 金得

  • 依芙琳（我的姑姑）
    • 手艺最好（做靴子）、爱抽烟、嘴毒、讲故事的人
    • 歪鼻子（四岁追灰鼠撞树折了鼻梁骨）
    • 全书"历史与规矩"的解说者：民族迁徙、左岸失地、氏族婚俗
    • 金得死后遭坤得鞭挞报复；1945 年冬怀孕后驾滑雪板一天自行流产报复坤得
    • 死：1969 年夏为玛克辛姆颈上烂疮"画圈吹气"九次，吹完最后一口气倒在篝火旁而亡
  • 坤得（依芙琳之夫，入赘）
    • 原爱阿巴河边一位蒙族姑娘，被迫娶依芙琳，终生冷落她
    • 东大营因走步出错被铃木秀男放狼狗撕咬，被伊万救下
    • 死：1969 年夏被安草儿捉来的一只黑蜘蛛吓死
  • 金得（依芙琳之子）
    • 相中妮浩，被鲁尼抢先后当众落泪，遭母亲捆在树上抽打
    • 被逼娶歪嘴的杰芙琳娜
    • 死：婚礼当日敬酒后离去，吊死在一棵枯松树上；按族规与那棵树一同火葬
    • 妮浩同日为他主持婚礼与葬礼

2.5 鲁尼 × 妮浩（子女死亡最惨重的一支）

  • 鲁尼（我的弟弟，后任族长）
    • 像父亲一样爱枪，百发百中；在妮浩即将离开时当众求婚，三日后把她"当猎物"抢回成亲
    • 死：妮浩死后约半年，喝着茶说"给我拿块糖来吧"，脖子一歪气绝
  • 妮浩（阿来克之女，尼都萨满之后的萨满 → 详见第五节）
    • 捡起尼都萨满丢弃的法器神衣；康德九年被神选中，由杰拉萨满主持出道
    • 每次跳神救活一人，便失去自己的一个孩子
    • 死：1998 年春跳神求雨成功，雨中未唱完神歌即倒地而亡
  • 六个孩子
    • 果格力：妮浩救何宝林之子时，爬上最高松树捉乌鸦坠落身亡
    • 交库托坎（百合花）：随柳莎采都柿时撞上马蜂窝，被马蜂蜇死
    • 耶尔尼斯涅（黑桦树）：十岁追畸形白鹿仔，被金河洪水卷走淹死
    • 贝尔娜：恐惧母亲跳神而逃走；妮浩葬礼上归来，葬后再度失踪（结局不明）
    • 玛克辛姆：存活；妮浩死后第三年出现萨满征兆（割腕、吞火炭、雨天奔跑），被隔绝神衣后渐趋正常
    • 未命名男婴：1960 年 8 月死产，妮浩救偷鹿少年所付出的代价；唯一没有名字的孩子

2.6 我的两任丈夫与后代

  • 第一任丈夫 拉吉达（族长）
    • 我迷山躲在"靠老宝"中，被他当成黑熊发现；"我的媒人是饥饿"
    • 守母孝三年后成婚，父亲送二十头驯鹿入赘
    • 任族长后把乌力楞分成小家庭、按人口均分兽肉
    • 死：白灾中骑吉田留下的马独自寻鹿，连日奔波在马背上打盹被活活冻死
  • 第二任丈夫 瓦罗加（"最后一个酋长"，识汉字、会写诗）
    • 1945 年贝尔茨河畔相遇成婚；把部族一分为二（齐亚拉率二十余人独立）
    • 拒任激流乡乡长；1965 年去激流乡一冬即回山
    • 死：1974 年夏送放映员途中，为救放映员与马粪包向母熊开枪，被母熊用前掌揭开头颅而死
  • 我的子女与孙辈
    • 维克特（子，拉吉达所生）
      • 妻柳莎（马粪包之女）→ 子九月
      • 1964 年秋用叫鹿筒诱鹿时误将弟弟安道尔当野鹿开枪打死，此后终日酗酒
      • 死：1976 年酗酒过度而亡，葬在伊万身边
    • 安道尔（子，拉吉达所生）
      • 性情痴愚忠厚；1959 年深秋被迫娶瓦霞
      • 死：1964 年被哥哥维克特误杀；此后全族不再用叫鹿筒、不再接近列斯元科山
    • 达吉亚娜（女，瓦罗加所生，1946 年秋生）
      • 夫索长林（氏族神枪手）→ 女依莲娜、索玛
      • 1965 年十九岁热衷新生活而去激流乡；依莲娜死后牵头联名建议下山定居
      • 把妮浩神衣神帽神裙捐给激流乡民俗博物馆
    • 孙辈
      • 九月（维克特之子，1956 年 9 月生）：激流乡邮局乡邮员；妻林金橘（汉族，商店售货员）
      • 安草儿（安道尔之子，1960 年 6 月生）：愚痴善良、手巧爱干活；妻优莲；唯一与我留在山上的人
      • 依莲娜（达吉亚娜之女，1968 年生）：部落第一位大学生，北京美院毕业，呼和浩特报社美术编辑
        • 死：进入新世纪那年春天宣布画成，当夜酒后去贝尔茨河洗画笔落水溺亡
      • 索玛（达吉亚娜之女，1978 年生）：厌学逃学，多次下山流产，诅咒驯鹿得瘟疫好让大家下山
      • 西班（马伊堪之子，无血缘，当作孙辈抚养）→ 见 2.7
    • 曾孙辈
      • 六月（九月 × 林金橘之子）
      • 帕日格（意为"背夹"）、沙合力（意为"糖"）：安草儿与优莲的双胞胎
        • 沙合力：酗酒闹事，纠人盗伐天然林卖黑材，判三年徒刑，结尾在狱中
  • 安草儿之妻 优莲
    • 相邻乌力楞的姑娘，因安草儿"心肠好"而愿嫁
    • 死：生下双胞胎后大出血而死；安草儿守尸四日不肯下葬

2.7 拉吉米系（无血缘的亲缘）

  • 拉吉米（拉吉达最小的弟弟，我的小叔子）
    • 家族十六口全部死于黄病，三岁时只剩他一人，被我接来抚养
    • 握着父亲留下的口弦琴木库莲；向达西学骑马
    • 东大营被铃木秀男识破（因吹木库莲），给吉田当马夫
    • 1945 年苏军轰炸时马受惊狂奔，阴囊撕裂、睾丸颠碎，失去男儿身
    • 此后拒绝一切提亲；结尾随西班去布苏
  • 马伊堪（拉吉米养女，实为扎兰屯大地主之女）
    • 1950 年夏被马贩子遗弃在乌启罗夫客栈马厩，由一匹银灰色马护着，瓦罗加起名
    • 高平路多次求婚被拉吉米拒绝
    • 死：1980 年三十岁失踪五日后归来并怀孕，冬天生下西班；西班两岁断奶后跳崖自杀
  • 西班（马伊堪之子，生父不明）
    • 从小啃树皮；造鄂温克文字、制作桦皮"玛塔"工艺品走俏于游客
    • 为拉吉米雕刻柞树犄角痰盂
    • 阻止玛克辛姆射杀灰鹤："得把这些灰鹤留给我和安草儿"
    • 下山去布苏（我原以为他不会走）

五、萨满传承链

5.1 传承顺序

  1. 旧萨满（无名）→ 去世三年后，新萨满产生
  2. 尼都萨满（林克之兄）
    • 为列娜跳神取"乌麦"，以一只灰色驯鹿仔代死
    • 主持林克风葬、鲁尼与妮浩婚礼
    • 死时：丢弃鼓槌、神鼓、神衣、神裙，倒地而亡
  3. 妮浩（鲁尼之妻）
    • 旧萨满去世第三年，由杰拉萨满主持出道仪式
    • 每次救人失去一子：果格力、未命名男婴（另有交库托坎、耶尔尼斯涅之死亦与之呼应）
    • 死时：1998 年求雨成功，雨中神歌未竟而亡
  4. 玛克辛姆（妮浩之子）
    • 出现萨满征兆（割腕、吞火炭、雨天奔跑、旱天大哭）
    • 族人藏起神衣神帽，隔绝其通神之路，最终趋向"正常"
    • 萨满传统在此断绝

5.2 "救一人，失一人"的代价

  • 救列娜 → 灰色驯鹿仔代死
  • 救何宝林十岁儿子 → 果格力坠树而死
  • 救马粪包（熊骨卡喉）→ 交库托坎被马蜂蜇死
  • 救偷鹿少年 → 未命名男婴死产
  • 救山中失明者、疥疮孩子、驯鹿瘟疫 → 尼都萨满自身的衰老与无能为力

七、时代坐标（对照人物命运）

7.1 三百多年前

  • 俄军入侵，祖先自勒拿河（拉穆湖）迁至额尔古纳河右岸
  • 十二个氏族只剩六个（左岸成为永远的失地）

7.2 清末民初

  • 漠河金矿开办（光绪—李鸿章—李金镛）
  • 妓院兴起，俄国安达贩卖女子 → 娜杰什卡的命运伏笔

7.3 伪满 / 日军时期（康德年间）

  • 日本人成立"满洲国"、满洲畜产株式会社（严重克扣）
  • 东大营"关东军栖林训练营"：铃木秀男强征十四岁以上男猎民
  • 娜杰什卡带子女逃亡；伊万越狱；拉吉米被毁；吉田自杀

7.4 建国后至文革

  • 1945 年：我与瓦罗加成婚，伊万以军人身份归来
  • 1950 年：乌启罗夫供销合作社成立；马伊堪被捡回
  • 1957 年起：林业工人进驻，伐木声响起
  • 1965 年：激流乡定居点建立，第二次大规模下山
  • 1968 年：文革，伊万、达西遭难
  • 1974 年：瓦罗加之死

7.5 改革开放至今

  • 1978 年后：依莲娜上大学，马伊堪之死，西班造字
  • 1998 年：妮浩求雨而死；大兴安岭大火（林业工人烟头所致）
  • 新世纪：依莲娜溺亡，达吉亚娜牵头联名，全体下山去布苏
  • 结局：山上只剩我与安草儿，以及逃回营地的白色驯鹿木库莲

  • 火种：那吉勒耶业 → 达玛拉 → 我（"这团火就是我跳动的心"）

  • 额尔古纳河：左岸是失地，右岸是新生；娜杰什卡的逃亡方向
